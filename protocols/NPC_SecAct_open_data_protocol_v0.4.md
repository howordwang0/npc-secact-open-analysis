# 鼻咽癌 SecAct 完全开放数据研究方案 v0.4

**冻结日期：** 2026-08-24  
**研究定位：** 患者级、跨 bulk RNA、单细胞和空间转录组的治疗相关分泌活动图谱  
**访问范围：** 只使用无需 DAC/PI 审批即可下载的数据  
**明确放弃：** 不再将本项目表述为 GP 诱导化疗疗效预测器，不等待或依赖 HRA006718

## 一、修订依据

两个完全开放的临床发现队列已经按预设方案完成：

- GSE132112：95 位患者，CR/PR versus SD 最低 BH FDR 0.9985，0 个候选。
- GSE103611：48 位患者，转移 versus 未转移最低 BH FDR 0.6097，0 个候选。

因此，不再通过新增临床终点、降低阈值或反复查看验证队列寻找阳性。本版本将问题从“预测谁获益”调整为“治疗后分泌活动如何变化，以及这些变化可能来自哪些细胞和组织区室”。这是新的系统生物学问题，不把既往阴性结果改写为阳性。

## 二、主要研究问题

鼻咽癌接受含免疫治疗的联合诱导治疗后，SecAct 分泌蛋白活动是否发生患者内重塑；这种 bulk 动态能否在开放单细胞数据中定位到患者级细胞来源，并在开放空间转录组中定位到相关组织区室？

### 统计单位

- bulk 配对动态：患者。
- 单细胞：患者 × 细胞类型 pseudobulk；细胞数不是生物学重复。
- 空间：患者/组织切片；spot、ROI 不作为额外患者。

## 四、Aim 1：开放 bulk 配对动态

本 Aim 已在独立冻结文件后完成，疗效标签未参与计算：

- 9位患者、每位BT/OT一对；`log2(x+1)`。
- SecActPy 0.3.1，`n_rand=1000`，GSL，seed 20260823。
- 657个独立签名组；512种完整sign-flip；BH FDR；2,000次患者对bootstrap。
- 动态门槛：exact sign-flip BH FDR <0.10、|Hedges gz| >=1.0、bootstrap同向率 >=0.90。

结果为163个广泛动态组（70上调、93下调）。它们构成两个冻结的动态集合，不被解释为163个独立生物标志物：

- `dynamic_up_set`：70组。
- `dynamic_down_set`：93组。

后续只检验这两个集合的整体方向和细胞/空间定位；单蛋白排名仅作描述。

## 五、Aim 2：患者级单细胞来源定位

### 数据审计和预处理

1. 对Zenodo 11个scRNA压缩包记录文件名、大小、MD5和内部格式。
2. 解析6位患者、BT/OT时点；要求P1只有BT，其余5位各有一对BT/OT。
3. 优先使用作者提供的处理后稀疏矩阵；不从细胞条形码推断临床响应。
4. 使用论文公开的主要细胞类型注释；若文件不含注释，使用作者论文标记进行粗粒度注释并保留不确定标签。
5. 每个患者×时点×细胞类型聚合为pseudobulk。只有至少4位配对患者、每位每时点达到预设最低细胞数的细胞类型进入动态分析。

### 推断和报告

- 首选在pseudobulk表达上运行与Aim 1相同参数的SecAct；若某细胞类型覆盖或稳定性不足，降级为相应ligand expression的pseudobulk描述。
- 对每个合格细胞类型计算`dynamic_up_set`和`dynamic_down_set`的集合分数，而不是重新筛选1170个蛋白。
- 只有5对患者，双侧sign-flip最小P为0.0625，因此不设置传统显著性门槛。
- 支持性定位需同时满足：集合方向与bulk一致、至少4/5患者同向、leave-one-patient-out方向不变。
- CR/non-CR仅可作为补充描述，不做推断统计。

### 禁止事项

- 不以细胞数作为n。
- 不在每个cluster分别筛657组后挑最好结果。
- 不把细胞来源定位解释为某个分泌蛋白的因果机制。

## 六、Aim 3：开放空间区室定位

### GSE206245

- 先按患者/切片建立manifest，审计15个NPC空间肿瘤的组织和平台映射。
- 每张切片计算`dynamic_up_set`和`dynamic_down_set`空间集合分数。
- 以肿瘤区、免疫/TLS区、基质区为区室，患者/切片为统计单位；spot只用于空间可视化和区室内汇总。

### GSE289272

- 只用于TLS区室补充；9个NPC患者而非40个独立患者。
- ROI先在患者内汇总，再比较预设区室或报告患者内分布。

### 空间支持标准

- 两个独立空间资源中至少一个集合显示相同的区室偏好；
- 患者级方向一致，不依赖单张切片或大量spot制造P值；
- 组织定位与Aim 2细胞来源在生物学上相容，但用“associated/localized”表述，不用因果语言。

## 七、Aim 4：外部背景和增量比较

只有在Aim 2和Aim 3都支持同一动态集合时才启动：

1. 在GSE150825/GSE150430中检查相同细胞类型的ligand expression背景。
2. 在GSE102349中将动态集合压缩成最多2个冻结分数；只做事件数允许的单变量和极简调整模型。
3. 与直接ligand expression、作者TME signature和简单临床基线比较，不只展示SecAct结果。
4. GSE224450只做降维覆盖/可运输性审计；覆盖不足则报告不可用，不强行推断。

## 八、Go/No-Go与期刊边界

### Go：可维持普通Q1首投

- bulk患者内动态稳健；
- 至少一个动态集合在患者级scRNA中获得来源定位；
- 至少一个开放空间队列提供相容区室定位；
- 相比ligand expression或常规TME signature有清楚增量；
- 完整报告两个公开临床队列的阴性结果和全部限制。

### No-Go：降为Q2/资源型文章

- 单细胞结果只在细胞层显著、患者层不一致；
- 空间定位依赖spot伪重复；
- 只有单个小队列支持；
- SecAct不优于直接表达或结果高度依赖预处理。

完全开放数据路线不再承诺高分Q1。若跨模态证据链完整，可尝试普通Q1；若缺独立患者级复制，更现实的是Q2。
