# 鼻咽癌 SecAct 项目数据审计简报 v0.3

**日期：** 2026-08-23  
**阶段：** GSE132112 正式发现分析完成  
**决策：** 原定诱导化疗预测器路线 no-go；不得放宽阈值追阳性

## 结果先行

GSE132112 的预设主要分析没有产生可冻结候选。95 位患者中 CR 32、PR 39、SD 24；657 个独立 SecAct 签名组中，主要终点 CR/PR versus SD 的最低原始 P 为 0.0208，最低 BH FDR 为 0.9985，0 个组达到 FDR < 0.05，0 个组通过“FDR < 0.05、|Hedges g| >= 0.5、bootstrap 同向率 >= 0.90”的联合门槛。

CR versus non-CR 敏感性分析最低 BH FDR 为 0.0595，仍未达到 0.05。它不能替代阴性的主要终点，也不能被重新命名为阳性发现。

## GSE132112 正式审计

- 下载文件：`GSE132112_nor_data_probelevel.txt.gz`，296,815,314 bytes，gzip 全文件校验通过。
- 原始矩阵：913,035 个 HTA 2.0 probe-selection-region 行 × 95 个样本。
- 官方设计映射：只使用 `pd.hta.2.0` 的 `core_mps`；排除 506 个跨 transcript cluster 歧义的 core PSR。
- 基因聚合：435,256 个唯一 core PSR -> 28,991 个 transcript cluster -> 23,205 个 gene symbol。
- 聚合规则：先在 transcript cluster 内取 PSR 中位数，再在 gene 内取 transcript cluster 中位数；过程不使用疗效标签。
- SecAct 实际覆盖：7,726/7,919 个签名基因，97.563%。此前 99.811% 是平台理论上限，不能替代实际矩阵覆盖。
- 样本 QC：无预定义相关性异常样本，未自动删除患者。
- 正式推断：SecActPy 0.3.1，1,000 次随机化，GSL RNG，seed 20260823，657 个独立签名组，2,000 次分层 bootstrap。
- 冻结清单：95/95 样本与 GEO 元数据一一匹配；SHA-256 为 `ad761c79633ff40e7797160c5d07f67a1077bb605272c28ed2b921429c8b8770`。

## 样本顺序风险

文件列顺序恰为 CR 1–32、PR 33–71、SD 72–95，疗效与提交/文件序号完全分块。PC1、PC4 和样本 IQR 在三组间有差异，但 GEO 不提供可用于区分真实反应生物学和实验批次的完整字段。因此 CR versus non-CR 的接近显著信号只能作为待外部检验的假设，不能在本队列内解释为稳定机制。

## 一区路线重估

当前公开数据仍可支撑有价值的鼻咽癌分泌信号研究，但不再支持直接建立 GSE132112 化疗预测器。后续只有两条合规路线：

1. **独立假设检验路线：** 将 CR versus non-CR 中排序靠前的信号明确标为探索性假设，只在患者不重叠、同类诱导化疗且含 CR 标签的外部队列中一次性检验。外部显著且方向一致后，才允许回到临床预测主张。
2. **跨情境系统生物学路线：** 重新预注册以转移、预后、治疗动态、单细胞来源和空间受体区室为并列问题；各队列独立发现或做层级模型，不再称为 GSE132112 候选的“验证”。

若缺少同治疗外部队列、患者级单细胞/空间一致性和增量价值证据，高水平一区首投成功率不应被高估。湿实验不是公开数据研究的形式必需项，但在当前主要终点阴性的情况下，功能实验也不能补救统计问题；首先应解决独立临床证据和批次不可识别性。

## 转移轴重启结果

在查看 GSE103611 表型关联前，v0.3 已冻结 GSE103611 发现和 GSE299775 验证门槛。正式结果仍为 no-go：最低原始 P 0.00448，29/657 个组未经校正 P < 0.05，但最低 BH FDR 0.6097；0 个组达到 FDR < 0.10，0 个组通过联合门槛。按方案不查看 GSE299775 的 MET/nonMET 关联，验证集保持盲态。
