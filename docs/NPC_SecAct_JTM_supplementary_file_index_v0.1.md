## Additional file 2

**File name:** `Additional_file_2_patient_specimen_level_derived_data.xlsx`  
**Title:** Patient- and specimen-level derived data  
**Description:** Machine-readable tables supporting the paired bulk,
single-cell, GeoMx, Visium, external spatial, and GSE102349 analyses. All IDs
are de-identified source-repository identifiers. A data-dictionary worksheet
defines every included sheet and its inferential unit.

## Additional file 3

**File name:** `Additional_file_3_frozen_protocols_and_deviations.docx`  
**Title:** Frozen analysis protocols and dated amendments  
**Description:** Consolidated protocols defining eligibility, statistical
units, program-freezing, multiplicity, robustness controls, missingness, and
permitted claim boundaries before the relevant analyses.
